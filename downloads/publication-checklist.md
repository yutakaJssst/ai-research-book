# GitHub Pages 公開前チェックリスト

## 内容

- [ ] 氏名、学籍番号、連絡先など、公開不要な個人情報が含まれていない
- [ ] 未公開の研究データ、共同研究先の秘密情報、審査中の内容が含まれていない
- [ ] APIキー、パスワード、アクセストークン、内部サーバー名が含まれていない
- [ ] 画像、文章、データの著作権とライセンスを確認し、必要な出典を示した
- [ ] AIが生成した文章・画像・コードを自分で確認した

## 表示と操作

- [ ] トップページから目的のページへ移動できる
- [ ] ページ内リンクとダウンロードリンクが切れていない
- [ ] 画像に代替テキストがある
- [ ] パソコンとスマートフォンの両方で読める
- [ ] ファイル名に機種依存文字や不要な空白がない

## GitHub

- [ ] 公開してよいファイルだけがコミット対象になっている
- [ ] READMEにサイトの目的と利用条件を記載した
- [ ] GitHub Pagesの公開元ブランチとフォルダーを確認した
- [ ] 公開URLをログアウト状態またはプライベートブラウズで開いて確認した
