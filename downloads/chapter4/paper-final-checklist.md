## 内容と根拠を確認する

| 項目 | 確認すること | 確認した箇所・残る作業 |
|---|---|---|
| 目的と結論 | 立てた問いに結果が答えているか。答えられなかった点も示したか | |
| Abstractと本文 | 方法、条件、数値、主張の強さが一致しているか。本文にない成果を加えていないか | |
| 方法と比較 | 対象、手順、データ、比較条件が分かるか。条件の違いを効果の違いと取り違えていないか | |
| 結果と数値 | 本文と図表の値、単位、件数が一致するか。元のデータや実行結果までたどれるか | |
| 解釈と限界 | 確かめた条件を超えて一般化していないか。別の説明や不確かな点を考えたか | |
| 用語と記号 | 同じ対象に同じ語・記号を使っているか。訳語が分野の意味に合っているか | |
| 図表 | 本文から参照され、何を示すか説明されているか。軸、単位、凡例、条件が読めるか | |
| 引用と参考文献 | 書誌情報と本文中の引用が対応するか。引用する主張を原文で確認したか | |
| 提出条件 | 語数、ページ数、ファイル形式、参考文献の書式などが指定に合っているか | |
| AI利用の開示 | 適用される規程に合わせて、使った作業と確認方法を説明しているか | |

確認できていない項目は、そのまま確認済みにせず、残る作業を書いてください。
結論を支える根拠が不足している場合は、主張を見直すか、追加の確認を行います。

## 文書作成ソフト、AI、人で分担する

図表番号、相互参照、参考文献の整形は、WordやLaTeX、文献管理ソフトの機能を使って管理します。
生成したPDFでも、参照先や図表の表示を確認してください。
語数やページ数は実際のファイルで数え、AIの自己申告だけで済ませないでください。

AIには、論旨がつながらない箇所、説明不足、用語の不統一を指摘してもらえます。
その指摘は、本文、原データ、実行記録、引用元と照合して採否を決めます。
AIが指摘しなかった箇所も、自分で読み直し、可能なら指導教員や共同研究者にも確認を依頼してください。
