## コードレビューの観点

自分のツールに関係する観点を選び、レビューを依頼するプロンプトに含めます。

| 観点 | チェック項目 |
|---|---|
| 可読性 | 変数名は内容を表しているか。コメントは十分か。関数は短いか。 |
| 効率性 | 不要な繰り返しはないか。目的に合ったデータ構造か。 |
| エラー処理 | 例外処理は適切か。エラーメッセージは明確か。 |
| セキュリティ | 入力値を検証しているか。秘密情報を埋め込んでいないか。 |
| 再利用性 | 関数に汎用性があるか。部品に分かれているか。 |
| テスト容易性 | テストしやすい設計か。依存関係は少ないか。 |

AIが見落とすこともあるため、指摘を読んだ後は、入力値と期待する結果を決めて自分でも動作を確かめます。

## 実行手順

### Google Colabで試す

[平均値関数とテストをColabで開く](https://colab.research.google.com/github/yutakaJssst/ai-research-book/blob/main/downloads/chapter6/average-tests.ipynb)から開き、先頭から順にセルを実行してください。
実行にはGoogleアカウントへのログインが必要です。
ノートブック内でpytestを準備し、本文と同じ関数と3件のテストをファイルにして実行します。
ファイルのアップロードとGPUは不要です。
編集した内容を残す場合は、「ファイル」から「ドライブにコピーを保存」を選びます。
`average-tests.ipynb` を保存すれば、手元のJupyterでも試せます。

### 手元のPythonで試す

1. Python 3 が使える環境を用意します。
2. 端末でこのフォルダを開き、`python -m pip install -r requirements.txt` を実行します。
3. `python -m pytest -v` を実行します。
4. 3件すべてが `PASSED` になれば、本文の例と同じ結果です。
