# SafeComp事例：統計の補足・訂正と検算

2026年10月20日改訂。書籍第7章のSafeComp事例を補う検証資料です。
論文執筆時の判断と数値を紹介した記録と、刊行後の今回の再計算を区別します。
この資料は刊行済み論文の本文を差し替えるものではありません。

## 何を修正したか

元の公開コードは、Wilcoxon符号付順位検定で、同順位があっても `method="exact"` を用いていました。
SciPy 1.13.1では、同順位やゼロ差がある場合、この指定だけでは正確なp値になりません。
また、Wilcoxonの効果量rに使う分散へ同順位を反映していませんでした。
今回のコードはゼロ差を除外し、差の絶対値が同じ回答に平均順位を与え、その順位のまま符号の全組合せを数えて両側p値を求めます。
乱数による近似ではなく、動的計画法による全組合せの計数です。
効果量rは、同順位を考慮した分散から求めるZの絶対値を、非ゼロ差の件数の平方根で割ります。連続性補正は用いません。
このrは近似的な標準化指標であり、正確なp値から逆算したものではありません。

| 比較・指標 | 論文執筆時／元コード | 今回の検算 |
|---|---:|---:|
| 技術的安全性：未補正p | 0.048828 | 0.056641 |
| 技術的安全性：Holm補正後p（5検定） | 0.146484 | 0.169922 |
| 契約要件：Wilcoxonのr | 0.886 | 0.921 |
| 境界明確性：未補正p | 0.000977 | 0.000977 |
| 境界明確性：Holm補正後p（6検定） | 0.005859 | 0.005859 |
| 境界明確性：Wilcoxonのr | 0.885 | 0.910 |
| ISO 26262の契約要件：OEMとサプライヤー間のMann–Whitneyのr | 0.629 | 0.629 |

境界明確性は15件のうち4件が中立の3で、非ゼロ差は11件です。
全11件が中立より低く、両側p値は `2 / 2**11 = 0.0009765625`、6検定でのHolm補正後は `0.005859375` となります。
役割分担の5検定も補正に含めています。本文にp値を載せなかった検定を、補正から外してはいません。

元のMann–Whitney検定は、同順位を考慮した正規近似と連続性補正でp値を求めています。rのZには連続性補正を使いません。
小標本での確認として、同順位を保った群ラベルの全組合せによる条件付きの正確検定も追加しました。
ISO 26262の契約要件では、p値は正規近似の0.001901に対し0.004348、5検定のHolm補正後は0.021739となり、この方法でも5％水準で有意でした。
同順位の処理とこの感度分析の範囲では、論文の4つの主要な有意所見は維持されています。
これは、検定の前提がすべて満たされたことを意味しません。

## 前提と解釈の限界

- 回答者同士の独立性を仮定しています。28社から30件の回答があり、2社は2名ずつ回答しています。匿名のため企業単位に集約した再分析はできません。
- 対象は機能安全ワーキンググループ参加企業の任意回答者です。日本の自動車産業全体への一般化や、企業の公式見解としての解釈はできません。
- Wilcoxon検定では、順序尺度であっても差の大きさに順位を付けます。差の順位の意味と、位置の差として解釈する際の対称性を検討する必要があります。
- 境界明確性については、差の大きさを使わない両側の正確な符号検定でもp値は0.0009765625です。符号検定にも独立性は必要です。
- 有意でないことは、差がないことの証明ではありません。標本数と非ゼロ差が少ない検定は特に慎重に解釈します。

## 実行する

Python 3.9以上を使い、次の3ファイルを同じフォルダへ保存します。

- [analyze.py（検算コード）](analyze.py)
- [check_statistics.py（独立した実装との照合）](check_statistics.py)
- [requirements.txt（必要なライブラリ）](requirements.txt)

```sh
python -m pip install -r requirements.txt
python analyze.py --output results.md
python check_statistics.py
```

データは著者の[公開再現用リポジトリ](https://github.com/yutakaJssst/SafeComp2026SurveyQuestionnaire)のコミット `0db8336d94d97e4be11f23b72cccd45a615e985b` から取得します。
SHA-256は `3d58873f2cd16f436596e5446589a43a4702cbfefe9534edc8de1d7c82a4d138` です。
一致しなければ処理を止めます。個票を本サイトへ複製せず、保存する結果も集計表だけです。
同じ公開CSVを手元に保存してある場合は、`python analyze.py --input responses.csv --output results.md` として使えます。
[再計算した全表](results.md)には実行環境も記録しています。
[独立した実装との照合コード](check_statistics.py)では、同順位・ゼロ差・小標本の正確検定をSciPyの全列挙と照合します。
